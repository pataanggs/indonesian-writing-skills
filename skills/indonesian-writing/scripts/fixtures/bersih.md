# Cara memilih CMS untuk perusahaan

WordPress dipakai 43% situs di dunia. Shopify memimpin untuk toko daring, Webflow untuk
situs pemasaran tanpa tim IT. Tiga pertanyaan berikut mempersempit pilihannya.

## Siapa yang akan mengelola

Kalau tim marketing mengisi konten sendiri, editor visual jadi syarat utama. Kalau semua
perubahan lewat developer, CMS berbasis kode justru lebih murah dirawat.

## Seberapa sering katalog berubah

Toko dengan 50 produk cukup memakai CMS bawaan. Katalog yang berubah tiap hari butuh
platform dengan API dan sinkronisasi stok otomatis.

## Berapa biaya tiga tahun

Harga langganan bukan biaya sebenarnya. Tambahkan biaya plugin, tema, dan jam kerja
developer. Angka ini biasanya dua sampai tiga kali lipat harga langganan.

## Yang sering terlewat

Migrasi data keluar dari CMS jauh lebih mahal daripada masuk. Tanyakan sejak awal apakah
konten bisa diekspor ke format terbuka. Beberapa platform mengunci konten di format
proprieternya.

Kalau kebutuhannya sudah jelas, uji dua kandidat selama 14 hari dengan konten sungguhan.
Jangan pakai data dummy.
